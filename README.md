# ELARIS - A 30-Book Digital Novel Saga

A premium digital book application and AI-powered storytelling engine for the epic fantasy saga **ELARIS**.

## Features

- **30 Books / 214 Chapters / 2,568 Pages** - Complete saga structure
- **AI Story Generation** - Connect any OpenAI-compatible API to auto-generate story content
- **Continuity Engine** - Tracks characters, nations, mysteries, and plot threads
- **World Encyclopedia** - Characters, nations, locations, magic systems, factions
- **Premium Reader** - Immersive reading mode, bookmarks, notes, full-text search
- **Dark Fantasy UI** - Cinematic design with gold accents on dark backgrounds
- **Persistent Storage** - All data saved in IndexedDB, survives refreshes
- **Export/Import** - JSON, TXT, Markdown backups

## How to Deploy

### Option 1: GitHub Pages (Recommended)

1. Create a new GitHub repository named `elaris-saga`
2. Upload `index.html` to the repository
3. Go to **Settings > Pages**
4. Set Source to **Deploy from a branch** > **main** / **root**
5. Your site will be live at `https://YOUR_USERNAME.github.io/elaris-saga/`

### Option 2: Run Locally

Simply double-click `index.html` to open it in your browser. No server needed.

## Usage

1. Open the application in your browser
2. Click **BEGIN** on the cover screen
3. Use the sidebar to navigate between Reader, Chapters, Encyclopedia, and more
4. Go to **Settings** to configure your AI API key
5. Click **Start Elaris** to begin AI-powered story generation

## Tech Stack

- Pure HTML + CSS + Vanilla JavaScript (no build tools required)
- IndexedDB for persistent browser storage
- Google Fonts (Cormorant Garamond + EB Garamond)
- OpenAI-compatible API integration
